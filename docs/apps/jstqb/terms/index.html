利用規約

JSTQB試験対策アプリの利用条件をご案内します。

制定日：2026年9月22日

この利用規約（以下「本規約」）は、pikacode（以下「運営者」）が提供する「JSTQB試験対策」アプリ（以下「本アプリ」）の利用条件を定めるものです。本アプリを利用することで、本規約に同意したものとみなされます。

第1条（本アプリの内容）

本アプリは、JSTQB試験の学習を支援するため、問題演習、模擬試験、学習記録その他の機能を提供します。公式の試験実施団体またはJSTQBの公式アプリではありません。

第2条（アカウント）

  1. 本アプリの一部機能を利用するため、Appleのアカウントを利用したログインが必要です。
  2. ユーザーは、自身のアカウントを適切に管理し、第三者に利用させてはなりません。
  3. アカウントの利用に関してユーザーに損害が生じた場合、運営者に故意または重大な過失がある場合を除き、運営者は責任を負いません。

第3条（コンテンツの権利と利用範囲）

  1. 本アプリに掲載される問題、解説、文章、画像、構成その他のコンテンツ（以下「本コンテンツ」）に関する著作権その他の知的財産権は、運営者または正当な権利者に帰属します。
  2. ユーザーは、本コンテンツを自らの個人的な学習目的の範囲でのみ利用できます。
  3. 本アプリの利用または購入によって、本コンテンツの著作権その他の権利がユーザーに移転することはありません。

第4条（禁止事項）

ユーザーは、運営者の事前の書面による許可なく、次の行為をしてはなりません。

  1. 本コンテンツの複製、転載、販売、貸与、再配布、公開または第三者への提供
  2. 本コンテンツを利用した教材、講座、研修、模擬試験その他のサービスの作成または提供
  3. 本コンテンツの全部または一部を営利目的で利用すること
  4. 本アプリの解析、改変、逆コンパイル、リバースエンジニアリングまたは不正なデータ取得
  5. 本アプリの運営を妨害し、または他のユーザーに不利益を与える行為

  3. 購読の解約は、Apple Accountのサブスクリプション管理画面から行ってください。
