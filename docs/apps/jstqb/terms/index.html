利用規約

JSTQB試験対策アプリの利用条件をご案内します。

制定日：2026年9月23日／最終改定日：2026年10月11日（同日施行）

この利用規約（以下「本規約」）は、「JSTQB試験対策」アプリ（以下「本アプリ」）の利用条件を定めるものです。本アプリを利用することで、本規約に同意したものとみなされます。

第1条（本アプリの内容）

本アプリは、JSTQB試験の学習を支援するため、シラバス解説、問題演習、模擬試験、学習記録その他の機能を提供します。本アプリは個人が開発した非公式の学習アプリであり、JSTQB・ISTQBおよび関係団体が作成・承認したものではありません。問題・解説・シラバス解説は独自に作成したもので、実際の試験問題や公式教材ではありません。

第2条（コンテンツの権利と利用範囲）

  1. 本アプリに掲載される問題、解説、文章、画像、構成その他のコンテンツ（以下「本コンテンツ」）に関する著作権その他の知的財産権は、運営者または正当な権利者に帰属します。
  2. ユーザーは、本コンテンツを自らの個人的な学習目的の範囲でのみ利用できます。
  3. 本アプリの利用または購入によって、本コンテンツの著作権その他の権利がユーザーに移転することはありません。

第3条（禁止事項）

ユーザーは、運営者の事前の書面による許可なく、次の行為をしてはなりません。

  1. 本コンテンツの複製、転載、販売、貸与、再配布、公開または第三者への提供
  2. 本コンテンツを利用した教材、講座、研修、模擬試験その他のサービスの作成または提供
  3. 本コンテンツの全部または一部を営利目的で利用すること
  4. 本アプリの解析、改変、逆コンパイル、リバースエンジニアリングまたは不正なデータ取得
  5. 本アプリの運営を妨害し、または他のユーザーに不利益を与える行為
  6. 法令または公序良俗に反する行為

第4条（有料機能と購入）

  1. 本アプリでは、Appleが提供するApp内課金を通じて、試験ごとの有料機能（以下「プレミアム」）を買い切りで提供します。対象は「CTFL プレミアム」「CTAL-TA プレミアム」「CTAL-TM プレミアム」「CTAL-TA・TM セット」です。
  2. 価格は購入画面およびApp Storeに表示します。支払いはAppleによる購入処理が完了した時点で行われ、プレミアムは処理完了後すぐに利用できます。
  3. プレミアムは買い切りであり、自動更新や追加の請求はありません。
  4. 購入はApple Accountに記録されます。再インストールや機種変更の後は、同じApple Accountで「購入を復元」を行うと利用できます。プレミアムはファミリー共有の対象外です。
  5. 同じシラバス版の間は、追加・改訂された問題や解説も追加料金なく利用できます。
  6. キャンセルおよび返金については、Appleの規約およびApp Storeの定めに従います。

第5条（サービスの変更・停止）

運営者は、保守、障害、セキュリティ上の必要その他の理由により、事前の通知なく本アプリの全部または一部を変更、停止または終了することがあります。本アプリの提供を終了する場合は、可能な範囲で事前に本ページまたはアプリ内でお知らせします。

第6条（免責）

  1. 本アプリは試験合格を保証するものではありません。
  2. 本アプリの情報は学習支援を目的としたものであり、試験内容、試験日程および制度については公式情報をご確認ください。
  3. 運営者は、本コンテンツの正確性、完全性および最新性の確保に努めますが、これらを保証するものではありません。
  4. 運営者の故意または重大な過失による場合を除き、運営者の軽過失によりユーザーに損害が生じた場合の運営者の責任は、当該ユーザーが本アプリに支払った金額を上限とします。

第7条（規約の変更）

運営者は、法令の改正、サービス内容の変更その他の必要がある場合、本規約を変更できます。変更内容および効力発生日を本ページに掲載し、重要な変更については可能な方法でお知らせします。変更後の規約は、表示した効力発生日から適用します。

第8条（準拠法）

本規約は、日本法に準拠して解釈されます。本アプリの利用に関して紛争が生じた場合は、適用される法令に従い、当事者間で誠実に協議して解決を図ります。
